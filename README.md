# Telugu Panchangam

A native Android calendar app for the Telugu Panchangam year (Ugadi → Ugadi),
written in Kotlin with Jetpack Compose.

The interface is deliberately monochrome: every background is white, every
piece of text is black or a gray step of it. Hierarchy comes from value,
weight and spacing rather than colour.

## Stack

| | |
|---|---|
| Language | Kotlin |
| UI | Jetpack Compose + Material 3 |
| Navigation | `navigation-compose` |
| Build | Gradle 9.1 / AGP 9.0.1 (built-in Kotlin) |
| Min / target SDK | 26 / 36 |

## Screens

- **Calendar** — month grid in the style of a general-purpose calendar app:
  hairline cell borders, today marked with a filled black disc, the tithi
  index under each date, and a compact chip where a festival falls.
- **Day detail** — masa/paksha, Shaka Samvat year, the five limbs
  (vara, tithi, nakshatra, yoga, karana), sun & moon times, Rahu Kalam /
  Yamagandam, and the eight day-Choghadiya periods.
- **Festivals** — the full year's festivals and observances, with per-item
  significance, observance and preparation notes.
- **About & sources** — provenance for everything the app displays.

## Data honesty

This is the part worth reading before trusting anything on screen.

**Verified.** Festival dates from 19 Mar 2026 through 24 Dec 2026 come from
the *2026 Drik Panchang Hindu Calendar* (Amanta system, Hyderabad, v1.0.4),
a real published almanac. Only the date and name of each occasion are taken
from it.

**Estimated.** The Jan–Apr 2027 entries (Makara Sankranthi, Maha Shivaratri,
next Ugadi) fall outside that document's coverage and are unverified
estimates, flagged as such in the UI.

**Placeholder.** Daily tithi, nakshatra, yoga, karana, sunrise/sunset,
moonrise/moonset, Rahu Kalam and Choghadiya values are generated by a
deterministic development stub in `data/MockRepositories.kt`. There is no
ephemeris and no lunisolar calculation behind them. Anything derived this way
is labelled *"Preview calculation"* in the app and must not be relied on for
religious observance.

**Withheld.** Mantra text, detailed shastric significance and exact observance
rules are not included. Where they would appear, the app shows
`[VERIFIED CONTENT REQUIRED]` rather than generated content, because these
require citation from a qualified traditional source.

The `domain/Repositories.kt` interfaces are the seam: a real deterministic
Panchangam engine can replace the mock implementations without the Compose
layer changing.

## Build

```bash
./gradlew :app:assembleDebug
```

The APK lands in `app/build/outputs/apk/debug/`. Set `sdk.dir` in
`local.properties` (gitignored) to your Android SDK path first.
